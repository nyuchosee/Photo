# 🖼 Фотопоток

**Фотопоток** — учебная галерея на UIKit. Изображения фильмов и мультфильмов собраны в сетку: выбери картинку, чтобы открыть её отдельно, а затем поделись ею через системное меню iOS.

## Что уже есть

- Коллекция из 18 изображений в две колонки.
- Отдельный экран для выбранного изображения.
- Кнопка, открывающая стандартное меню **«Поделиться»**.
- Изображения хранятся в `Assets.xcassets` и загружаются по имени.

Это учебная галерея с заранее добавленными изображениями. Она не читает фототеку устройства, не загружает фотографии из интернета и не позволяет добавлять свои изображения.

## Что я здесь изучаю

- **Swift и UIKit**: `UICollectionViewController`, `UICollectionViewCell`, `UIImageView` и `UIViewController`.
- Источник данных коллекции и переиспользование ячеек.
- **`UICollectionViewDelegateFlowLayout`**: расчёт размера ячеек, отступы и интервалы.
- **Storyboard и segue**: переход на экран изображения и передача выбранной картинки.
- **`UIActivityViewController`** для системного меню обмена.

## Как запустить

1. Склонируй репозиторий или скачай его через **Code → Download ZIP**:

   ```bash
   git clone https://github.com/nyuchosee/Photo.git
   ```

2. Открой в Xcode **`Фотопоток/Фотопоток.xcodeproj`**.
3. Выбери схему **Фотопоток** и симулятор iPhone, затем нажми **⌘R**.

В исходных настройках проекта указаны **iOS 14.5** и режим языка **Swift 5**; проект создан в Xcode 12.5.1. На более новой версии Xcode может понадобиться обновить настройки проекта.

## Где что находится

```text

├── Фотопоток.xcodeproj

    ├── PhotoViewController.swift              # Просмотр и меню «Поделиться»

    └── SceneDelegate.swift
```
